# Hari Tharshini T | Personal Portfolio

A clean, highly professional, single-page personal portfolio designed for a Senior Software Engineer. The design focuses on extreme elegance, readability, and a standard corporate/agency feel with massive amounts of whitespace and pristine typography.

## 🚀 Live Preview
*`https://thars2004.github.io/haritharshini/`*

## ✨ Features
- **Pristine Classic Architecture**: Organized into clear, easily digestible vertical sections (Hero, About, Experience, Skills, Projects, Contact).
- **Responsive Single-Page Layout**: Fully responsive design with a custom mobile dropdown navigation menu.
- **Professional Light Theme**: A crisp, high-contrast palette using Slate grays and a Corporate Blue accent color.
- **Understated Animations**: Utilizes AOS (Animate On Scroll) for very subtle, smooth fade-up animations.
- **Curated Content**: Showcases a massive grid of 20 college and professional projects cleanly without clutter.
- **Optimized SEO**: Fully configured with meta tags, keywords, and Open Graph tags for rich social media sharing.

## 🛠️ Tech Stack
This project is extremely lightweight and does not require any build tools or package managers (no `npm` or `node_modules`).
- **HTML5**: Semantic markup for the single-page application.
- **Tailwind CSS**: Styling is handled entirely via Tailwind CSS (injected via CDN).
- **AOS (Animate On Scroll)**: For elegant scroll-triggered animations.
- **FontAwesome**: For lightweight, scalable icons.
- **Vanilla JavaScript**: For the mobile navigation toggle and dynamic copyright year.

## ⚙️ How to Run Locally
Because the project is completely static and uses CDNs, there are zero installation steps required.

1. Clone or download the repository.
2. Ensure you have an active internet connection (required to fetch the Tailwind CSS and AOS CDNs).
3. Open `index.html` in any modern web browser.
